# Bronafbeeldingen · source images

Hier staan de referentieafbeeldingen die `cad/dieren/trace.py` overtrekt. De bestandsnamen staan in de
`Bron(...)` van elk personage:

| Bestand | Gebruikt door |
|---|---|
| `mario.webp` | `cad/dieren/mario.py` (foto van een Mario-kussen) |
| `sonic.png` | `cad/dieren/sonic.py` |
| `spiderman.png` | `cad/dieren/spiderman.py` |
| `steve.webp`, `creeper.png` | ter referentie; Steve en de Creeper zijn als pixelraster getekend |

Het auteursrecht op deze afbeeldingen ligt bij hun makers (Nintendo, SEGA, Marvel, Mojang/Microsoft en de
fotografen). Ze horen **niet** in een publieke repository. Ontbreekt een bestand, dan stopt `bouw.py` met een
melding die zegt welk bestand er moet staan.

*Reference images traced by `cad/dieren/trace.py`. Copyright belongs to their owners; keep them out of public
repositories. If a file is missing, `bouw.py` stops and names the file it needs.*
